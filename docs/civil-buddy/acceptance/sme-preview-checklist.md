# SME 预览版验收记录模板

本文件是待填写模板，不是已通过的测试报告。真实资料和填写后的记录保存在个人工程中，避免上传公共仓库。

| 记录项 | 实际值 |
|---|---|
| 操作人 / 日期 | 待填写 |
| 电脑 / 操作系统 / Python 版本 | 待填写 |
| 发布版本 / 源码提交 | 待填写 |
| ZIP SHA-256 / 校验器结果 | 待填写 |
| 独立工程与状态目录 | 待填写，不记录口令 |
| 使用资料 | 合成 / 已获授权的真实资料：待填写 |

| 步骤 | 验证内容 | 结果与证据位置 |
|---|---|---|
| 安装 | 在另一台电脑完整解压，创建虚拟环境，按需安装依赖，校验发布包 | 待验收 |
| 登录 | 独立用户启动；未登录请求被拒，退出与重启后旧 Cookie 无效 | 待验收 |
| 演示 | 合成 façade demo 完成，并明确标注合成来源；草稿不自动批准或提交 | 待验收 |
| CAD | 只采用原图明确的尺寸，确认单位与实体，尺寸/孔洞对应，GLB 导出重开 | 待验收；缺少高度/长度时停止 |
| 计划 | 核对工期、日历、依赖与资源来源，关键线路、改参、撤销正确 | 待验收；缺项保留为空 |
| 箱单 | 每个字段核对页码/单元格，逐包装数量、尺寸和重量一致 | 待验收；OCR 不可用须明确失败 |
| 保存恢复 | 保存并正常关闭两进程，重新启动后继续修改；原件哈希不变 | 待验收 |
| 同事交接 | 业务项目包 / 岗位会话包导入为新副本；附件、来源、交付物可下载且哈希相同；签认清除 | 待验收 |
| 取消 | 显示正在停止；完成前同一会话不能再执行/导出；停止后不启动新步骤 | 待验收 |
| 隔离 | 无法通过另一实例的项目 ID、路径、会话 ID 访问其资料 | 待验收 |

岗位会话包不包含 Rust Agent 的执行数据库。同一归属的完整恢复需备份工程与状态目录；不要把身份数据库、登录口令或模型密钥交给同事。

未通过项、复现步骤与后续责任人：待填写。只有实际完成的步骤才能记为通过；同机换目录不能记作第二台电脑验收。
