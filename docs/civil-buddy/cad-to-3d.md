# CAD → 3D 建模助手（预览）

将 **已确认用途的二维实体轮廓 + 用户给定的高度或长度** 转成真实三角网格，
在浏览器里旋转、缩放、选择构件、修改参数，再导出 GLB 和参数记录。
首版同时提供建筑平面、构件截面两种模式。两者共用确定性几何程序，
命令解析器只修改受限参数，不调用模型，不执行生成的 Python，不编造顶点。

这是几何预览工具；没有完整的 Revit/BIM 构件语义，不能作为设计签认件。
仓库附带的图纸均为**合成测试样例**。本地真实图纸已用于二维选区、孔洞和大图导入检查，
但部分图纸缺少明确的拉伸长度，尚未完成真实项目的三维交付验收。
样例和自动测试通过不代表任意施工图都能转换；用户原图和本地验收材料不进入公开仓库。

## 启动

在项目环境安装基础依赖和 CAD 依赖，然后启动工作台：

```powershell
python -m pip install -r requirements.txt
python -m pip install -r requirements-cad.txt
python -m packing_assistant.civil app
```

打开工作台首页的「CAD → 3D 建模助手」，或在工作台地址后访问 `/cad`。
CAD 附加依赖为 `ezdxf`、`shapely`、`trimesh`、`mapbox-earcut`。
没有安装时，页面会列出缺失依赖，安装后可重新检测。

需要 STEP 实体导出时，另装 `python -m pip install -r requirements-cad-step.txt`。
它使用可选 CadQuery/OCP 内核；没有安装仍可预览和导出 GLB。

统一与 Python 源码包均包含这份可选依赖清单。已安装主项目、CAD、工程与 STEP
依赖后，可用 `python scripts/native_engineering_acceptance.py --with-step` 运行零跳过门禁；
统一包还可用 `python scripts/native_engineering_runtime.py --binary bin/civil-workbench.exe --with-step`
经临时具名实例验证签认导出和实际 STEP 文件重开。输入仍为合成样例，不代表真实图纸验收。

首页根据后端声明的能力显示 CAD 入口；仅提供旧工作台接口的后端不会显示不可用入口。
配置 `CIVIL_TOKEN` 时，CAD 使用与工作台相同的访问口令。直接打开 `/cad` 可在页内输入口令；
登录后重新检测能力，不需要重新上传已在页面中的图纸。访问口令与导出签认句是两个独立步骤。

## 两种模式

| 模式 | 明确输入 | 建模结果 | 参数修改例子 |
| --- | --- | --- | --- |
| 建筑平面 | 墙体实体边界、柱子截面、楼板实体边界，分别对应已确认图层 | 单层墙、柱、板，各自按高度/厚度和底标高拉伸 | `墙和柱高3米，楼板厚120毫米` |
| 构件截面 | 同一图层内的外轮廓及内孔边界，用户指定拉伸长度 | 保留贯通内孔的棱柱类构件 | `把拉伸长度改为6米` |

这些例子中的尺寸来自用户输入。系统不会从房间名称、图层名称、图片或相邻构件
推测建筑高度、板厚、截面长度。墙的平面厚度取自原轮廓，不在首版参数命令中改写。

**不要把房间边界当成墙体实体。** 如果一条封闭轮廓围住整个房间而没有明确内外墙边界，
直接拉伸会得到实心块。请先在二维视图核对图层和轮廓的含义；无法确认实体区域时不要生成。
图层名称只用于提出映射建议，用户必须确认用途及实体区域含义。

## 可接受的 DXF

- 直接上传 DXF；首版不导入 DWG。只有 DWG 时，请先用 CAD 软件另存为 DXF。
- 支持闭合、零线宽的 `LWPOLYLINE` 或二维 `POLYLINE`，包括正负 bulge 圆弧。
  位于世界 XY 平面，原图 Z 为 0；高度与底标高在建模面板指定。
- 同一图层的 `LINE` / `ARC` 可按相接端点组成闭合轮廓；缺口或分支会明确失败，不补线。
  `CIRCLE` 可作为外轮廓或孔洞。圆弧按确认的原图单位重新离散，默认弦高误差上限
  **0.1 mm**；可在面板调整为 0.001–10 mm，设定值和实际最大弦高写入参数记录。
- `INSERT` 支持平面内平移、旋转和正数统一缩放，可嵌套；保留块实例路径、原实体编号与图层。
  非统一缩放、镜像或非平面变换不支持。离散所需顶点超限时拒绝，不悄悄放宽误差。
- 曲线边界过近、现有离散误差无法可靠判断相交或孔洞关系时，整层暂停并提示减小误差。
  大坐标的浮点舍入不能代替闭合校验；超出固定物理精度范围的接点不合并。
- 必须确认原图单位，支持毫米、厘米、米、英寸、英尺。
  单位缺失或不明确时不猜测；界面参数统一换算为米。
- `SPLINE` 支持 1–5 次、正权重、夹持节点的平面 NURBS。通过精确节点插入及 Bézier
  控制包络细分限制弦高误差，记录实际误差；过密、自交、回折无法可靠离散等情况明确拒绝。
  未闭合样条只可与同层线/弧/样条组成可验证的闭环，不自动补线。
- 开口线段、椭圆、不符合上述条件的样条、带宽度的笔画、非平面轮廓等不作为实体边界。
  不自动补线或修复自交；不支持的块变换也必须清理后再建模。
- 同一建模图层的选中轮廓相交、重合、相切，或者仍含无效/不支持实体时，
  **该图层整体标记失败**。可以明确排除重复实体和无关图框，但不能通过漏选内边界填实孔洞。
  未选内部边界或位置不明的不支持实体仍会阻止建模，并在报告中说明。
- 同一图层内严格嵌套的边界按内外包含关系保留贯通孔洞。
  孔洞随所属实体一起拉伸，不能单独修改孔洞高度。
  不同图层的对象各自独立，不自动做布尔合并或洞口扣减。

门窗洞口自动识别、楼梯、屋顶、多层对齐、复杂曲面和任意施工图自动还原不属于首版能力。
未处理的实体会显示状态和原因；请查看报告，不要只检查三维画面是否出现。

## 实体选择、诊断与尺寸来源

二维图支持点选、Shift 多选、框选、滚轮缩放和平移。先选中对象，再使用「仅建选中」或
「排除选中」改变实际建模选集；视图分组用于保存、恢复选中对象。选集、排除项和分组跟随项目保存。
「只查看此组」只改变视图，不改变建模范围。预检会填充材料区域并留空孔洞；不需要先填写高度。
点击开口、重复、相交或漏选孔洞诊断，可以定位对应实体与问题点。系统不自动修复原图。

尺寸面板将原图 DIMENSION 标注值、几何测量值与建模参数分开显示。
例如文字标注 1500、实测 1499.816，会同时保留；只去除 DXF 文字格式，不将混合文字猜成数值。
用户必须明确选择来源、角色或已有构件以及参数用途，服务端据原图换算数值并保存来源编号。
截面宽、高不会自动成为拉伸长度。未标明长度时保持空白，不能生成三维模型。
改参数或排除绑定对象会解除过期来源绑定；撤销可恢复之前的配置与绑定。

## 大图分阶段导入

10 MiB 以内可直接严检；较大 DXF 先扫描概览，最多 64 MiB。
概览只抽样展示最多 2000 个顶层路径或块包围框，重复块先计数，不全部展开；概览不是建模结果。
用户选定有效图层和原图坐标区域后，才对相关实体严格解析。跨区边界不会被裁切或悄悄闭合；
区域选择也不能把外边界丢掉后将内孔当成完整材料。
严格建模仍受实体数、块深度、离散顶点数和精度预算限制；超过预算要求缩小范围或整理原图。
取消扫描或严检不替换已有图纸和模型。完整原图摘要与筛选范围随项目保存，重开时重放筛选。

接口：`POST /api/cad/import/scan` 上传 DXF；`POST /api/cad/import/select` 提交
`import_id`、`layers` 与可选 `bounds`；`POST /api/cad/analyze` 提交 `document_id`、`config`；
`POST /api/cad/bind-dimension` 提交同样上下文及 `binding`。

## 操作顺序

1. 上传 DXF。二维视图显示原轮廓和图层，同时查看解析结果及未支持实体。
2. 选择「建筑平面」或「构件截面」，确认原图单位，指定各图层为墙/柱/板/截面/忽略。
3. 输入对应角色的高度、板厚或拉伸长度，以及底标高。
   确认所选轮廓代表实体区域后生成模型。
4. 在三维视图旋转、缩放和平移，选择构件查看来源图层、原图实体编号和参数。
   查看成功、忽略、失败的逐实体记录；部分图层失败会在记录中保留。
5. 在面板或命令框修改参数，确认预览更新。存在尚未生成的参数修改时，撤销先恢复当前模型参数；
   否则撤销返回上一次已生成的模型。
6. 填写项目名，保存草稿或保存当前模型版本。可以从最近项目重新打开，选择旧版本后另存成新版本。
7. 导出前完整键入：`我明白，将由持证人员签认`。
   可以下载 GLB、参数 JSON、包含两者的 ZIP，以及安装可选内核后的 STEP。

预览只要求确认轮廓的实体含义，不需要签认句。导出生成可带走的文件时，服务端也会检查
上述完整签认句，不能用勾选框或命令解析替代。

未保存的图纸与模型仍使用约 30 分钟的临时缓存，重启或容量不足会释放。
**显式保存后的项目不依赖缓存**：原始 DXF、单位、图层用途、参数、来源编号和处理报告
保存在工作台输出目录 `demo/out/_cad/<项目编号>/project.json`，使用现有路径校验、进程间锁和原子替换。
原图内容保持不变；模型按已保存的原图和版本参数重建，不信任导入包中的顶点。

草稿与已生成版本分开：未填完的参数可以存草稿，生成失败保留上一个可用模型；恢复项目时
可同时显示未完成草稿和上次模型。保存带修订号，其他页面或 Agent 更新后返回冲突，不覆盖新版本。
同参数重复保存不增加模型版本；每个项目最多 50 个模型版本，最多 100 个项目、总计 512 MiB。
达到上限会说明原因，不自动删除历史。

项目包用于同事交接，包含原始 DXF 与版本记录，最大 80 MiB。导出也要求签认句及当前修订号；
导入校验摘要、尺寸、路径和版本，创建新项目编号并清空签认状态。另一个工作台安装相同 CAD 依赖后
可导入并继续修改。损坏包不覆盖已有项目；本地损坏记录显示错误，不当作空项目覆盖。

项目接口：`GET /api/cad/projects` 列表；`POST /api/cad/projects` 保存（`name`, `document_id`,
`config`, 可选 `model_id`；更新还须 `project_id`, `expected_revision`）；
`GET /api/cad/projects/{id}` 恢复草稿及上次模型，`?version=N` 打开指定版本；
`POST /api/cad/projects/import` 上传项目 ZIP；`POST /api/cad/projects/{id}/export`
提交 `confirmation` 和 `expected_revision`。读取响应均禁止缓存。

## 统一 Agent 对话

保存后点击「在工作台用 Agent 继续 ↗」，对话会绑定该项目。工具包括检查图纸、建议图层、生成、
修改参数、撤销和导出，共用 CAD 页的几何服务。`steps` 模式无需模型；`model` 模式由模型
选择受限工具，工具仍只从**本轮用户输入**提取尺寸。不会执行模型生成的代码，也不接受模型提供的
项目路径、坐标、确认状态或参数字典。

可输入 `检查图纸`、`建议图层`、`生成模型`、`把墙高改成3.6米`、`撤销上次修改`、`导出模型`。
图层建议只展示，需返回 CAD 页确认。修改显示「原值 → 新值」，成功结果写入新版本；
冲突或失败不能回复已保存。模型没有实际调用成功的工具时不能声称已生成。
导出继续使用当前轮用户亲自输入的签认句，历史确认或模型文字不能授权导出。
当前版本的自然语言操作限于已支持的确定性命令；面板始终可用。

## 参数命令

支持有限、完整匹配的中文和基础英文指令。距离必须有明确单位，多个修改可以用逗号或
分号连接；所有子句都成功才返回修改后的参数。有一句不能识别或校验失败，整条消息不生效。

| 目的 | 指令 |
| --- | --- |
| 统一墙高 | `把墙高改成3.6米` |
| 同时改墙与柱 | `墙和柱高3米` |
| 改楼板拉伸厚度 | `楼板厚120毫米` |
| 改柱底标高 | `把柱子标高改为0.2米` |
| 只改选中实体 | `把选中构件高度改为3米` |
| 修改截面构件长度 | `把拉伸长度改为6米` |
| 过滤已有用途 | `只建墙和柱` |
| 忽略指定图层 | `忽略 FURNITURE 图层` |
| 多个修改一起生效 | `墙高3.6米，柱高3米，楼板厚120毫米` |
| 英文参数修改 | `set walls and columns height to 3.6 m` |

角色级修改会同步该角色已有构件的同名覆盖参数，例如改全部墙高后，曾单独设过高度的墙
也采用新高度；它们的底标高和其他参数保留。只改一个构件时，请先选中该构件再下指令。

「只建」仅过滤已经确认的用途，不会把未指定用途的图层猜成墙或柱。「忽略」使用实际图层名；
例如图纸中的 `FURNITURE` 不会因为用户写了「家具」而被自动翻译匹配。恢复被忽略的用途、
新增映射、确认单位、切换模式请用参数面板。

问题、否定、缺单位、零或负高度、非有限数值、互相冲突的多个值以及未知动作均拒绝执行。
例如 `墙高3米吗`、`不要改墙高3米`、`墙高3.6`、`墙高3米，墙高4米` 都不会改模型。
底标高允许用户明确给出 0 或负数。源图坐标、单位和实体确认状态不由命令修改。

## 文件与尺寸追溯

GLB 包含真实可重新加载的网格，长度单位为米，使用 Y 轴向上。内部预览几何采用 Z 轴向上；
导出进行确定的坐标轴变换。参数 JSON 记录原图名称与摘要、确认的单位、平移原点、
坐标轴映射、图层用途、角色参数、构件覆盖参数、来源实体编号、孔洞信息及处理报告。

为避免大坐标降低显示精度，预览会移动原点；移动量与单位换算都写入记录。
调高度不改变源图 XY 轮廓和预览原点；改选图层可能重定原点，新的平移量会记入记录。
被忽略的图层不会拉远预览原点。若多个选中构件相距过远，转为浏览器和 GLB 使用的
float32 网格时会损失薄壁尺寸，工具会明确拒绝失真图层，避免显示或导出被压扁的实体。
参数 JSON 不代替原始 DXF；要复核原图实体或重建模型，应同时保留两者。

STEP 根据已验证模型的离散二维外轮廓和孔洞生成毫米制实体，保留孔洞、高度及底标高；
导出后在内存中重新读取，检查实体数、包围尺寸与体积。它与预览使用相同离散轮廓，
不是原生 NURBS 曲面、建模历史或完整 BIM。STEP 同样执行服务端签认和取消检查。

## 验证与实际图纸验收

```powershell
python scripts/test_cad_commands.py
python scripts/test_cad_geometry.py
python scripts/test_cad_selection.py
python scripts/test_cad_dimensions.py
python scripts/test_cad_imports.py
python scripts/test_cad_workflow.py
python scripts/test_cad_step.py
python scripts/test_cad_api.py
python scripts/test_cad_projects.py
python scripts/test_cad_agent.py
node scripts/test_cad_ui.cjs
```

命令测试检查原图/配置不被修改、显式单位、角色及对象级修改、多子句原子性与拒绝情形。
几何测试负责尺寸、单位换算、曲线误差、块实例、孔洞、闭合网格和 GLB 重新加载；
接口与持久化测试覆盖独立进程恢复、保存中断/取消、版本冲突、损坏包及导出边界。
Agent 测试使用离线脚本模型，覆盖参数来源、越权拒绝、取消和跨轮撤销。
测试不访问真实模型服务。

真实图纸到位后，建筑平面与构件截面应分别完成下列验收：

- 人工确认原图单位、实体区域和至少一组可复核尺寸，检查模型尺寸没有千倍缩放错误。
- 检查明确的内孔仍为空洞，未实现的门窗等在处理记录中可见。
- 修改一个高度或长度，核对平面轮廓和其他构件参数保持正确，并测试撤销。
- 导出 GLB 后用独立查看器重新打开，核对尺寸、方向、对象数量和参数记录。
- 保存后重启工作台继续修改；同事导入项目包后核对原图摘要、模型尺寸、孔洞和版本参数一致。
- 逐项核对忽略与失败的实体，记录原图中不符合首版条件的内容。

只有对应实际图纸完成这些检查，才能报告该场景验收通过。
