Civil Buddy: the tender response and the packing plan, linked

For façade (curtain-wall) subcontractors who answer English tenders and ship panels in containers.

This server is private. To use it, open the link ending in ?token=... that you were given (for the hackathon judges: through the organiser's form). The browser then keeps the token in an HttpOnly cookie for 30 days, and /demo runs the linked demo in one click.
需要访问口令：请打开发给你的带 ?token=... 的链接。

What it does

  • Reads the tender's logistics clauses: container type, gross mass per loaded container, securing, stillages and handling, delivery sequence.
  • Plans the panel list (Excel or CSV) into containers of the type the tender names, with the same planner and conservation checks as the packing tool.
  • Writes one English statement per clause, each tied to its clause, a plan figure, and the sha256 of the tender, the panel list and the plan. A statement the plan does not support goes to a named person; nothing is marked covered without plan evidence.
  • When the panel list changes, it names the statements that went stale and must be re-confirmed.
  • Qualifications and price stay with people. Every record is an internal draft: submit_blocked = true.

Run it yourself, without this server

pip install -r requirements.txt
python scripts/demo_facade.py          # the same linked run on the SYNTHETIC demo files, no API key

or with Docker: CIVIL_TOKEN=<a long random string> docker compose up --build, then open http://localhost:8000/?token=<that string>.

Everything on a demo server is synthetic (fictional tender, fictional panels). Liveness: /api/health.
