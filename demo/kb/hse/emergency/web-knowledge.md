## SG
- SCDF Fire Code 2023（官方全名 Code of Practice for Fire Precautions in Buildings 2023）。只列章名，不引条款数字。https://www.scdf.gov.sg/fire-safety-services-listing/fire-code-2023 ；目录：https://www.scdf.gov.sg/fire-safety-services-listing/fire-code-2023/table-of-content
- SCDF Code of Practice for Fire Precautions in Road Tunnels (CPFPRT) 2025。只写题名。https://www.scdf.gov.sg/fire-safety-services-listing/code-of-practice-for-fire-precautions-in-road-tunnels-(cpfprt)-2025
- SCDF Emergency Response Plan（由原 Fire Emergency Plan 扩展，整合 FEP / IPP / APP）。https://www.scdf.gov.sg/fire-safety-services-listing/emergency-response-plan
- 指定场所举例：有 Fire Certificate 且容纳超过 200 人的公共建筑；工业用地面积或场地至少 5 000 m² 或容纳至少 1 000 人；外劳宿舍同上阈值；医院；P&FM 持证贮存场所须按 SCDF 指引编 ERP 并交 HazMat。
- 法规题名：Fire Safety (Emergency Response Plan) Regulations。SSO：https://sso.agc.gov.sg/SL/FSA1993-RG4?DocDate=20200911
- SCDF 页：须委任 Fire Safety Manager 的场所每年至少 2 次疏散演练 + 2 次桌面推演；不须 FSM 的指定场所每年至少 1 次疏散演练。本岗不宣布演练合格。
- 工伤 / 危险事件法定报告走 MOM，不是 SCDF ERP：Workplace Safety and Health (Incident Reporting) Regulations。雇主：死亡尽快通知 Commissioner，10 日内交 incident report；非死亡自知悉起 10 日内报告。占用人报公众/自雇住院或死亡、以及 Dangerous Occurrence（无论是否受伤）。本轮 MOM 主站部分页面维护，口径依既有官方页。https://www.mom.gov.sg/workplace-safety-and-health/work-accident-reporting/what-and-when-to-report
- 工地急救另有 Workplace Safety and Health (First Aid) Regulations（立法表列出，适用于 all workplaces）。火警救援拨 SCDF，电话以项目正式通讯录为准，草稿不预填。
