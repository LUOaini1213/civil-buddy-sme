# 室内装修 · 联网知识（2026-08-14）

岗位对应：饰面、隔墙、吊顶、防水界面。不改主体结构、不编承载力。装修不得缩小疏散宽度。

辖区：仅以用户明确给定资料为准；未给则 UNSPECIFIED，不默认新加坡或中国。总体辖区不能补入对象空栏；CN / SG / EU 来源分别归属，不静默混用。本页是注明日期的历史检索参考，不是规范全文库或当前已核验依据；未抽出原文的标准只写全名，条款 UNSPECIFIED。

公开口径：
- 精装是二次设计时必须叠在已审主体图上，标出本次范围与借用的疏散和消防设施。
- 不得把主体承重墙当隔墙拆除。装修消防走室内+消防双岗，不单方放行。
- 《建筑防火通用规范》为强制性工程建设规范；与现行标准不一致时以该通规为准。
- 施工图未经审查合格不得使用。

公开口径：
- 改建/装修可属 building works。BCA 称 Approved Document 提供符合 Building Control Regulations 的 acceptable solutions。
- 无障碍走 Code on Accessibility 2025（官方称第六次修订，适用于新建及 A&A）。Companion Guide 是非强制建议，不把建议当坡度/净宽数字。本岗不编坡度数字。
- CONQUAS 是新建工程质量评估，不是装修审图替代件。页列三大部分（适用于 2023-07-01 起招标的项目）：Internal Finishes（楼地面、内墙、天花、门窗及基本机电配件）；Installation Methods Verification and Functional Tests（卫生间防水、石材/瓷砖、木地板、窗安装及水密/粘结等）；External Finishes（屋面、外墙、室外工程，竣工阶段评估）。本岗只写组分名，不编分项分与 band。评估须在开工前申请。
- 改变用途或改平面而影响疏散、防火分隔、消防系统或空调通风的，属 fire safety works，须先取得 SCDF 图纸批准（豁免或 MAA 另按官方页判定）。
- 吊顶隐蔽空间、封堵、饰面燃烧性能只对 SCDF 章名 Concealed Spaces / Fire Stopping / Classification of Spread Of Flame，不编耐火小时数与燃烧等级数字。

## 通用
